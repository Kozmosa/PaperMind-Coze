## Slide 1 — 封面（5秒）

各位评委老师好，我是项目负责人徐阳。今天带来的项目是 **Papermind：多智能体驱动的知识自生长系统**。

我们打造了一条从"导入"到"反思"的全链路智能学习闭环，让 AI 帮助每一位学习者把碎片知识编织成网、把学习过程沉淀为洞见。

## Slide 2 — 当前知识学习的核心痛点（40秒）

先看三个真实的痛点。

**第一，知识碎片化严重。** PDF、课堂笔记、网页摘录散落在不同工具里，人工整理耗时易错。移动端的碎片化阅读更是加剧了信息割裂，最终形成一个个无法串联的"信息孤岛"。

**第二，AI 与私域知识脱节。** 像 ChatGPT、通义千问这样的通用大模型，完全不了解你的学习历史和私有文档，给出的回答缺乏个人知识锚点。它无法基于你的认知背景提供有深度的定制化解答。

**第三，学后即忘，无反思闭环。** 学习者很难量化自己真正掌握了什么，缺少系统化的反思工具来回顾、梳理和关联新旧知识。投入了大量时间，产出却不成正比。

**我们的答案就是 Papermind**——一个基于多智能体的主动式知识管理系统。它有四个核心能力：

- **自动结构化**：多源异构知识自动清洗、分类与图谱构建，消除信息孤岛。
- **可深度追问**：基于个人知识库提供有根有据的专属解答。
- **能自我生长**：越用越智能，动态关联新旧知识，形成知识复利。
- **会智能反思**：智能生成学习复盘与薄弱点分析，构建闭环成长路径。

## Slide 3 — 系统全景：数据库驱动的多Agent协作（45秒）

来看系统全景图。

整个系统的运转围绕四个 Agent 展开。左上角是 **Knowledge Builder 知识构建 Agent**——它接收上传的 PDF、PPT 等文件，自动完成内容解析、分类和结构化处理，为系统提供原始知识库。处理结果写入中央数据库。

数据库是整个系统的"大脑皮层"——也是所有 Agent 的**唯一通信媒介**。每个 Agent 只读写数据库，从不直接相互调用。这带来了四个关键架构优势：

- **唯一通信总线**：数据流转的绝对一致性，彻底消除了信息孤岛。
- **松耦合架构**：Agent 之间零直接依赖，可以独立开发、独立部署、独立升级。
- **价值闭环流转**：一个 Agent 的结构化输出——比如分类后的知识——直接成为另一个 Agent 的输入，形成正向增强的智能循环。
- **模块化扩展**：按需灵活插拔功能模块，快速适配多样化的教育场景。

数据库下方是三个并行的消费端 Agent：**Tutor 导师**基于溯源数据提供精准问答，**Note Helper 笔记助手**自动提炼学习重点生成结构化笔记，**Reflection Mind 反思 Agent** 则基于全量交互数据生成反思报告、反哺知识库优化。

## Slide 4 — MVP1 Knowledge Builder：全自动分类流水线（65秒）

进入 MVP1，Knowledge Builder。这是系统的"咽喉"——所有知识入库的第一站。

左边是**全链路自动化处理流程**，分三步走。

**第一步，多源解析与质量预检。** 支持 PDF、PPT、Markdown 等异构文档，自动执行格式解析和可读性清洗，剔除无效信息，为后续知识提取建立标准化的输入基础。

**第二步，摘要生成与层级分类。** 这是核心。系统为每份文档生成 80 到 150 字的高浓缩 Papercore——涵盖核心观点和方法论的学术摘要。然后基于预训练的学科树完成 L1、L2 两级学科自动归类，输出结构化 JSON 数据。

**第三步，知识萃取与图谱构建。** 系统智能注入 Top-8 高频已有标签，利用字符重叠度算法——同位置字符重叠超过 75% 就强制合并——避免标签冗余。经过后处理清洗后，将结构化知识写入数据库，同步更新知识图谱。

右边展示了三项**关键技术优势**：

- **动态学科树**：实时同步最新学科体系到 Prompt，确保每一次分类都基于最新的知识树，避免体系滞后导致的归类偏差。
- **智能标签合并**：基于字符重叠度自动聚合相似标签，防止标签碎片化，大幅提升后续检索效率。
- **全量覆盖保障**：对于损坏或不可读的文件，自动触发降级策略，根据文件名推断主题、生成基础 Papercore，实现 100% 入库率。

底部的核心机制是整个 MVP1 的灵魂——**知识体系的自生长与迭代**。系统具备"增量学习"特性——每处理一个文件，即刻更新内存中的学科树权重与标签库。后续文件可直接复用历史沉淀的分类结果，模拟人类认知的积累过程，实现"越用越智能"的正向增强循环。

## Slide 7 — MVP2 Note Helper：多源综合与自学习笔记（65秒）

进入 MVP2，Note Helper 笔记助手。如果说 Knowledge Builder 解决的是"知识怎么存"，Note Helper 解决的就是"知识怎么记"。

左侧是**交互与数据流转的闭环**，同样三步：

**第一步，用户触发与请求发起。** 用户在学习资料页面选中若干知识节点或材料，点击"生成笔记"，前端调用 `/generate-note` 接口，实时传递文档内容与交互上下文。

**第二步，智能抽取与偏好融合。** 后端抽取各源内容的核心信息，同时从数据库加载用户的历史笔记风格偏好，将其自动注入到 LLM 的 System Prompt 中。这意味着笔记还没开始生成，AI 就已经知道你喜欢什么样的笔记了。

**第三步，流式生成与动态渲染。** LLM 通过 SSE 流式输出结构化 Markdown 笔记，后端进行后处理——提取每个来源标注 ±80 字的上下文——前端即时渲染，引用可以定位到原文。

右侧两个特性是 MVP2 的**核心创新**：

- **渐进式偏好学习**：用户拿到笔记后，如果觉得不够详细，点一下"更详细"按钮；或者直接输入"加一个对比表格"。系统自动从自然语言反馈中提取关键词——"更详细"映射为 detail_level: high，"加表格"映射为 prefer_tables: true——然后与已有偏好增量合并存入 `papernote_style` 表。不是覆盖，是合并。

- **动态 Prompt 注入**：下次生成笔记时，这些偏好自动注入 System Prompt："用户偏好：详细程度高、偏好表格对比、语言通俗"。无需手动设置，零配置个性化。用户通过自然交互"训练"笔记助手，每一条反馈都是训练数据。

右下角的总结非常到位——**"将被动阅读转化为主动知识生产，实现学习效率的指数级提升"**。

## Slide 9 — MVP3 Tutor 智能导师：三层检索与溯源问答（65秒）

MVP3，Tutor 智能导师。这是四个 Agent 中技术复杂度最高的一个——它要解决的问题是："在我的知识库里，怎么找到最相关的那个答案？"

左侧是**三层递进式检索引擎**。

**Layer 1，知识节点精确锚定。** 如果用户在提问前选择了具体知识节点——比如"帮我解释一下刚才学的留数定理"——系统直接按 ID 级精准匹配，毫秒级响应，跳过后续所有语义检索。

**Layer 2，跨表语义增强检索。** 这是核心技术。系统启动时用 BGE-small-zh-v1.5 中文嵌入模型对四张核心业务表——knowledge_nodes、study_notes、materials、file_contents——构建统一向量索引。用户提问后，问题向量化做余弦相似度匹配，同时引入**标签权重加成算法**：问题向量去搜索标签库，找出语义相关和字面匹配的标签，共享标签越多的记录分数越高，最高加 30%，大幅提升弱相关问题的召回精度。

**Layer 3，兜底保障机制。** 前两层无有效结果时，自动加载最近 100 个知识节点、50 条笔记、50 份资料作为上下文，确保服务连续不中断。

右侧是**可信生成与数据闭环体系**，同样三块：

- **上下文动态组装注入**：检索结果不是直接丢给 LLM。我们按来源类型回源拉取完整字段——papercore、标签、原文内容、页码——与知识图谱关联信息深度融合，统一注入 System Prompt，构建完备的推理上下文。
- **强制引用与五色溯源**：系统在 Prompt 层面强制约束模型输出引用标记 `【来源：文件名，第N页】` 或原文引用块 `「原文…」`。前端用五种颜色区分来源类型——紫色知识节点、绿色学习笔记、橙色原始资料、灰色带页码的原文片段、黄色图片——点击即可一键跳转至原始文档，实现"结论→证据→原文"的完整闭环。
- **全量数据闭环沉淀**：所有问答交互以结构化格式存入 `problem_solving_logs` 表，为后续的反思引擎和数据迭代提供持续的燃料。

## Slide 11 — MVP4 Reflection Mind：多源反思引擎（55秒）

最后一个 MVP——这也是我们跟市面上所有产品最不一样的地方——Reflection Mind，反思之心。

左侧是**触发与多源采集**。用户打开专用反思界面，自主选定复盘周期——3 天、7 天或 30 天，一键启动引擎。系统并行拉取四类核心数据：学习难点记录、Tutor 对话日志、历史反思报告以及知识图谱节点活动度，消除数据盲区。这背后是一个核心设计原则：**基于事实的客观复盘，而非主观模糊的自我总结。**

中间是**AI 驱动的生成工作流**，分三步。Step 1 上下文构建：将全量采集数据深度注入 System Prompt。Step 2 四维度生成：LLM 流式输出学习行为分析、问题攻克复盘、思维模式洞察和优化建议，每个维度 200 到 400 字。Step 3 资产沉淀：正则解析四段内容，结构化存入 Reflections 表，形成可积累、可对比的个人成长数字资产。

右侧是**可视化与认知闭环**。通过图表直观呈现学习活跃度与反思效果，帮助用户从"被动学习"转向"主动认知管理"。到这一步，整个知识飞轮真正闭合了——**学→问→记→思**，形成一个正向增强回路，有效提升长期记忆留存率。

## Slide 13 — 核心创新点与竞品对比（40秒）

总结一下，Papermind 有四个不可复制的差异化创新。

**第一，Papercore + 纯 LLM 分类。** 我们摒弃了传统 Embedding 向量依赖，实现全格式文件 100% 覆盖。依托大模型语义理解构建自生长的智能标签体系，无需人工干预——而且分类过程完全可解释。

**第二，自适应笔记 Agent 自学习。** 无需复杂参数配置，通过自然语言交互持续训练模型，精准捕捉用户的知识偏好、记录习惯和思考逻辑，越用越懂你。市面上没有一个产品做到了这一点。

**第三，语义与标签双路融合检索。** 独创三层检索架构——精确锚定 + 跨表语义 + 标签加成——实现毫秒级响应速度和知识溯源的精准闭环。

**第四，全链路反思增强闭环。** 打通"知识输入→深度内化→智能输出→系统反思"的完整飞轮。

## Slide 14 — 后续优化方向（15秒）

未来的三个优化方向：

**第一，多端接入、降低门槛。** 打通微信生态，用户转发文件到服务号即可实现资料自动入库，大幅降低知识沉淀的操作成本。

**第二，技术深化、增强理解。** 引入 MathOCR 等前沿技术强化数学公式识别，深度优化对理工科文献的解析和语义理解能力。

**第三，智能切分、精准溯源。** 对 PDF 和 PPT 做更细粒度的版块切分和内容结构化，实现从"定位到某一页"到"定位到某一段"的精度跃升。

右边是我们知识图谱的可视化预览——基于多维度学术数据构建的关联网络结构，直观呈现文献、知识点之间的复杂关系。
