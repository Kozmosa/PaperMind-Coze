# 迭代法解线性方程组

> 数值分析 · 解线性方程组（下）
> 前置：直接法（高斯消元、LU 分解），见同目录《解线性方程组的数值解法》

---

## 一、为什么还需要迭代法

对大型稀疏方程组（如偏微分方程离散后的矩阵，阶数 $10^5$ 以上、每行非零元仅个位数），直接法的消元过程会引入大量填充（fill-in），时间与存储都不可接受。迭代法只做矩阵-向量乘，**保持稀疏性**，且可以在达到精度后随时停机。

## 二、基本构造：分裂格式

将 $Ax = b$ 的系数矩阵分裂为 $A = M - N$（$M$ 易求逆），得到**定常迭代**：

$$
x^{(k+1)} = M^{-1}N x^{(k)} + M^{-1}b \quad\Longleftrightarrow\quad x^{(k+1)} = G x^{(k)} + f,
$$

其中 $G = M^{-1}N = I - M^{-1}A$ 称为**迭代矩阵**。

| 方法 | $M$ | 迭代格式（分量形式） |
|---|---|---|
| Jacobi | $D$（对角） | $x_i^{(k+1)} = \dfrac{1}{a_{ii}}\left( b_i - \sum_{j\ne i} a_{ij}x_j^{(k)} \right)$ |
| Gauss-Seidel | $D + L$（对角+下三角） | $x_i^{(k+1)} = \dfrac{1}{a_{ii}}\left( b_i - \sum_{j<i} a_{ij}x_j^{(k+1)} - \sum_{j>i} a_{ij}x_j^{(k)} \right)$ |
| SOR | $\frac{1}{\omega}(D + \omega L)$ | $x_i^{(k+1)} = (1-\omega)x_i^{(k)} + \dfrac{\omega}{a_{ii}}\left( b_i - \sum_{j<i} a_{ij}x_j^{(k+1)} - \sum_{j>i} a_{ij}x_j^{(k)} \right)$ |

Gauss-Seidel 一算出新分量立刻投入使用，单次迭代只需一份向量的存储；SOR 引入松弛因子 $\omega$（$0 < \omega < 2$），$\omega > 1$ 超松弛加速、$\omega < 1$ 低松弛增稳。

**例** 解 $\begin{cases} 4x_1 - x_2 = 3 \\ -x_1 + 4x_2 - x_3 = 2 \\ -x_2 + 4x_3 = 1 \end{cases}$，取 $x^{(0)} = 0$（真解 $x^* = (1,\ 1,\ 0.5)^T$，可代入验证）。

- Jacobi 第一步：$x_1^{(1)} = \frac{3}{4},\ x_2^{(1)} = \frac{2}{4},\ x_3^{(1)} = \frac{1}{4}$（三个分量都用旧值）；
- Gauss-Seidel 第一步：$x_1^{(1)} = \frac{3}{4}$，接着 $x_2^{(1)} = \frac{2 + x_1^{(1)}}{4} = \frac{2.75}{4}$，再 $x_3^{(1)} = \frac{1 + x_2^{(1)}}{4}$——同一步内信息即时更新，通常收敛更快。

## 三、收敛性：谱半径是唯一标尺

**定理（收敛充要条件）** 迭代格式 $x^{(k+1)} = Gx^{(k)} + f$ 对任意初值收敛 $\iff$ 谱半径 $\rho(G) < 1$。

且误差压缩比渐近为 $\rho(G)^k$：$\rho$ 越小收敛越快。任何从属范数都满足 $\rho(G) \le \|G\|$，所以 $\|G\| < 1$ 是**充分条件**（易验证但保守），$\rho(G) < 1$ 才是充要条件（需算特征值）。

**定理（对角占优充分条件）** 若 $A$ 严格对角占优（每行 $|a_{ii}| > \sum_{j\ne i}|a_{ij}|$），则 Jacobi 与 Gauss-Seidel 均收敛。

**定理（SOR 的必要条件）** SOR 收敛 $\Rightarrow 0 < \omega < 2$；当 $A$ 对称正定且 $0 < \omega < 2$ 时 SOR 必收敛。

**常见误区**（错题本高频）：

1. 系数矩阵不严格对角占优 **≠** 迭代发散——对角占优只是充分条件，不满足时必须回到谱半径判据；
2. Gauss-Seidel 不总比 Jacobi 快（存在反例矩阵），"GS 一定快"是错误印象，只是对多数实际问题成立；
3. $\rho(G) = 1$ 时不是"收敛慢"而是**不收敛**（临界情形需更细致的分析）。

## 四、误差控制与停机准则

绝对误差 $\|x^{(k)} - x^*\|$ 不可得（真解未知），实用的停机准则：

$$
\frac{\|x^{(k+1)} - x^{(k)}\|}{\|x^{(k+1)}\|} < \varepsilon.
$$

注意：相邻迭代量接近**不保证**接近真解（病态问题里步长小可能只是收敛慢）——迭代的收敛速度与矩阵条件数相互纠缠：$\kappa(A)$ 大时即便迭代收敛，解对 $b$ 的扰动也敏感。

## 五、与最优化的一座桥

把视线从"解方程"移到"求最小"：解对称正定方程组 $Ax = b$ 等价于最小化凸二次函数 $\phi(x) = \frac{1}{2}x^TAx - b^Tx$。最速下降（负梯度方向）与共轭梯度法（CG，共轭方向）都在这个框架下：CG 在精确算术下 $n$ 步收敛，实质是 **Krylov 子空间上的最优迭代**。SOR 与 CG 是大型稀疏方程组的两大流派；而"迭代矩阵谱半径决定收敛"与梯度下降中"条件数决定收敛速度"一脉相承——这正是数值分析与机器学习训练共享的数学骨架（参见《机器学习数学基础导读》第三节）。
