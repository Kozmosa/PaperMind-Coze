# PaperMind 演示场景包 · 「期中复习周」

场景人设：**数学系大二学生「小禾」，期中考试前一周**。学科组合为复变函数 / 数理统计 / 数值分析，外加自学中的机器学习（形成跨领域知识图谱）。时间线横跨近 30 天：早期上传的资料已读过，近一周的新资料带红点待查看，QA 日志在期中临近时明显加密。

## 快速开始

```bash
# 1. 启动前后端（Expo :5001 / Express :9091）
pnpm dev

# 2. 导入场景数据（需 .env 已配置 ANTHROPIC_API_KEY 与 SUPABASE_*；tsx 是 server 依赖，需在 server 目录执行）
cd server && npx tsx scripts/seed-scenario.ts
#    追加 --light 可只重灌社区/反思/会话/QA 日志等轻数据（不触发 LLM，秒级完成），适合迭代场景文案：
#    npx tsx scripts/seed-scenario.ts --light

# 3. 演示入口（三选一）
#    a. App 前端     http://localhost:5001          （真实客户端）
#    b. 浏览器调试页 http://localhost:9091/debug/full-app-test.html （直连后端的联调页）
#    c. 调试预览壳   http://localhost:9091/debug/preview.html
```

> seed 是**可重入**的：每次运行先清空演示用户的全部数据（含社区表），再完整重建。
> 全程约 3-6 分钟（20 份文档 × 3 次 LLM 调用 + 本地 BGE 向量化）。

时间线设计（控制中心「最近记录」与反思折线图依赖）：

- 纪要：26 天前 → 4 天前均匀分布，**9 天前的已查看**，近 8 天的带红点；
- 资料：17/14/12/10 天前（已查看）、7/5/3/1 天前（带红点）；若对资料执行过「重新分析」，`viewed_after_process` 会被重置，红点数在 7~9 之间浮动；
- QA 日志按 `DAILY_QA_COUNTS` 分布（最近 5 天加密，期中冲刺形态），共 52 条。

## 10 分钟演示剧本

按 Tab 顺序走一遍即覆盖全部核心功能。**加粗**为推荐讲解话术点。

1. **控制中心（首页）**
   - 统计卡：学习纪要 12 / 上传资料 8 / 待查看红点约 7；
   - 最近记录按时间倒序混排纪要与资料，近一周条目带红点；
   - 点一条带红点的资料 → 进入资料页 → 返回，**红点消失**（mark-viewed）。
2. **知识库（图谱）**
   - 图谱视图：多领域圈 + L1/L2/L3 三层标签树，**复变/统计/数值的 L3 标签有重叠**（留数、迭代法等）；
   - 捏合缩放、点击标签 → 弹出该标签下的文档列表；
   - 切到文件夹视图：`/学习资料/机器学习/` 等目录树可浏览。
3. **AI 助手（chat）**
   - 打开左侧历史会话面板 → 点「留数定理复习」→ **消息带 4 类引用卡**（知识节点紫 / 纪要绿 / 资料橙 / 文件内容灰带页码），点击引用卡可查看来源；
   - 新建对话，问一个 `qa-expectations.md` 里的问题（推荐第 1 题）→ 流式回答 + 引用卡；
   - 点「我明白了！」→ 该问答写入 QA 日志（可到「我的 → 解题日志」验证当日 +1）。
4. **多选生成笔记（NoteHelper）**
   - 回到控制中心或知识库 → 多选「留数定理笔记 + 解析函数讲义」→ NoteHelper 面板 → 生成；
   - 全屏笔记页：`[n]` 引用标记可点击，右侧源文件列表；试「表格对比」「举例子」快捷修正。
5. **反思（我的 → 学习反思）**
   - 历史报告卡片（7 天前的期中自评）→ 详情页 4 维度 + **近 7 天 QA 折线图**；
   - 现场生成：选 7 天 → 流式生成新报告 → 自动跳详情（对比历史报告，新报告窗口不同）。
6. **社区**
   - 省流墙 3 条 public 便利贴 + 好友区 1 条；「复变函数期中互助组」论坛 2 帖；
   - 现场发一条便利贴 → 删除。

## 已知边界（演示时避开）

1. **draft-pool 页「处理为节点」按钮**跳转的 `/knowledge-node-edit` 路由不存在（已知 bug，会落 404）——演示时不要点。
2. **刚 seed 完立即提问**可能检索不到最新内容：向量索引有 5 秒防抖重建，seed 结尾已调 `/ai/refresh-index`；若仍怀疑，等 10 秒再问。
3. **纯英文检索质量有限**：embedding 模型是中文 BGE，本场景包刻意以中文内容为主。
4. **重复跑 seed**会清掉你在演示中产生的所有数据（含新发的帖子）。
